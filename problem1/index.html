Three ways to sum to n

sum_to_n(5) = 1 + 2 + 3 + 4 + 5 = 15. Each number i is a column of i blocks, so the sum is a staircase. Pick a method, press Play, and watch how each one builds that same staircase — one by one, all at once, or by diving down and climbing back up.

Same answer, very different cost

    

    

      

        A · Loop
        
O(n) time · O(1) space

        
    
          
  • Easiest to read and to prove correct.
    • 
          
  • n additions; fine up to millions.
    • 
          
  • Never blows the stack.
    • 
        

      

      

        B · Gauss formula
        
O(1) time · O(1) space

        
    
          
  • Two staircases make an n × (n+1) rectangle; halve it.
    • 
          
  • Constant time for any n.
    • 
          
  • Watch the precision limit: results above 253 lose accuracy.
    • 
        

      

      

        C · Recursion
        
O(n) time · O(n) space

        
    
          
  • Mirrors the maths: sum(n) = n + sum(n − 1).
    • 
          
  • Every call waits on the stack until the base case.
    • 
          
  • Large n throws RangeError: Maximum call stack size exceeded.
